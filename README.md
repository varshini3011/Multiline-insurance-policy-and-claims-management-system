# Multi-Line Insurance Policy and Claims Management System

## 📌 About the Project

The **Multi-Line Insurance Policy and Claims Management System** is a Salesforce-based application developed to manage **Auto, Property, and Life insurance policies and claims** in a single platform.

It helps automate policy quoting, premium calculation, claim routing, claim approval, and provides a dashboard for claims adjusters.

## 🎯 Objectives

- Manage multiple types of insurance policies.
- Automate policy quoting using Salesforce Flows.
- Calculate premiums using Apex.
- Automate claim routing.
- Manage high-value claim approvals.
- Provide a Claims Adjuster Dashboard.
- Implement security using Permission Sets and Sharing Rules.

## 🛠️ Technologies Used

- Salesforce
- Apex
- Lightning Web Components (LWC)
- Salesforce Flow
- SOQL
- Approval Processes
- Permission Sets
- Sharing Rules

## ✨ Key Features

- Auto, Property, and Life Policy Management
